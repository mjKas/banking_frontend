# BankingApp Frontend

BankingApp Frontend is the client-side application developed by Manuja Rajakaruna as part of the practical assessment for the Critical Systems Development MSc module offered by the University of Staffordshire, UK.

The frontend provides a responsive and user-friendly interface for the BankingApp system, enabling secure user authentication and interaction with the backend banking services through REST APIs.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- React Router

## Features
- User registration interface
- Secure login system
- JWT token handling
- Two-factor authentication (2FA) verification UI
- Responsive dashboard interface
- API integration with Spring Boot backend
- Form validation and error handling

## Backend Repository
This frontend application communicates with the BankingApp backend API developed using Spring Boot and Spring Security.
